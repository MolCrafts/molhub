# Positioning

MolHub is the discovery, addressing, transport, submission, and inspection layer of the MolCrafts
ecosystem. It does not host the authoritative scientific payload and it does not replace scientific
record or visualization libraries.

The registry assigns a stable coordinate to approved metadata. Python and TypeScript clients resolve
that coordinate and fetch one role. The Web app lets people browse, submit, review, and open compatible
roles in Inspector. MolVis renders structures, MolPlot renders property maps, and MolRec defines derived
records.

The product Web answers “what exists and can I inspect it?” This manual answers “how do I use and
operate it?” The website never maintains a second handwritten dataset catalog.
